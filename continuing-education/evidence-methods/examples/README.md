# CME Development Examples

This directory is reserved for worked examples showing how the CME development framework is applied.

Examples should be added only when they demonstrate a reusable educational or methodological lesson.

Potential examples include:

- a completed clinical module;
- a source-to-claim traceability table;
- a case-based learning example;
- an assessment-item development example;
- an epistemic provenance audit;
- a before-and-after example showing correction of evidence-strength inflation;
- a narrative corroboration spillover example;
- an example of compound-claim decomposition.

## Example Requirements

Each example should:

- identify whether it is fictional, composite, or based on a real educational activity;
- preserve `[REF]` markers when sources have not been independently verified;
- avoid fabricated citations;
- distinguish educational synthesis from source-established findings;
- explain important methodological decisions when useful.

Do not place patient-identifiable information in this directory.
